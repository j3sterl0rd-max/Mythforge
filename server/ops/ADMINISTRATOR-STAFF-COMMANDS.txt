MYTHFORGE ADMINISTRATOR COMMAND GUIDE

Replace <values> with the requested names, numbers or IDs; do not type the brackets. Use Tab for available values.
Coordinates are x y z. ~ uses your current coordinate. @s selects yourself; @a selects all online players; @e selects all entities.

/AFK
====

Displays the AFK bypass list.
/afk bypass-list

Adds a player to the AFK bypass list so AFK handling can exempt them according to the AFK mod's settings.
/afk bypass-list add <player>

Removes a player from the AFK bypass list.
/afk bypass-list remove <player>

Changes another player's AFK state.
/afk toggle <player>

/BAN
====

Bans the named account from joining. Add a reason to record why the ban was issued.
/ban <targets>
/ban <targets> <reason>

/BAN-IP
=======

Bans a connection address, or the address of an online player, from joining. Other players sharing that address can also be affected.
/ban-ip <target>
/ban-ip <target> <reason>

/BANLIST
========

Lists current bans. Use players for account bans or ips for address bans.
/banlist
/banlist ips
/banlist players

/CHUNKY
=======

Displays Chunky help and task controls.
/chunky

Cancels a chunk-generation task. Existing generated chunks remain.
/chunky cancel
/chunky cancel <world>

Sets the center of the generation selection.
/chunky center
/chunky center <x>
/chunky center <x> <z>

Resumes a paused chunk-generation task.
/chunky continue
/chunky continue <world>

Defines the generation area using two opposite corners.
/chunky corners
/chunky corners <x1>
/chunky corners <x1> <z1>
/chunky corners <x1> <z1> <x2>
/chunky corners <x1> <z1> <x2> <z2>

Displays Chunky help, optionally for the named command.
/chunky help
/chunky help <page>

Pauses chunk generation without deleting its progress.
/chunky pause
/chunky pause <world>

Shows chunk-generation progress and speed.
/chunky progress

Sets the generation radius in blocks, with separate axes where supported.
/chunky radius
/chunky radius <radius>
/chunky radius <radius> <radius>

Reloads Chunky configuration from disk.
/chunky reload
/chunky reload <type>

Displays the current generation selection.
/chunky selection

Chooses the generation selection's shape.
/chunky shape
/chunky shape <shape>

Moves the selection center to the selected world's spawn.
/chunky spawn

Starts generating chunks inside the current selection. This can create substantial server load.
/chunky start
/chunky start <world>
/chunky start <world> <shape>
/chunky start <world> <shape> <centerX>
/chunky start <world> <shape> <centerX> <centerZ>
/chunky start <world> <shape> <centerX> <centerZ> <radiusX>
/chunky start <world> <shape> <centerX> <centerZ> <radiusX> <radiusZ>

Selects the world/dimension used by subsequent Chunky commands.
/chunky world
/chunky world <world>

Copies the selected world's Minecraft world border into the generation selection.
/chunky worldborder

/CLEAR
======

Removes inventory items from the selected player(s). An item limits what is removed; a maximum count limits the number removed. A count of 0 only counts matching items.
/clear
/clear <targets>
/clear <targets> <item>
/clear <targets> <item> <maxCount>

/CREATEBYPASS
=============

Shows the named player's manual machinery-bypass status.
/createbypass <player>

Removes the manual machinery bypass. Machinery already unlocked through playtime or rank remains available.
/createbypass <player> off

Grants the named player access to the gated Create machinery before their normal playtime unlock. Banned items remain banned.
/createbypass <player> on

Shows whether the named player has a manual machinery bypass.
/createbypass <player> status

/DEATHHISTORY
=============

Displays the selected player's recorded death locations/history. A UUID can be used instead of a name.
/deathhistory <player>
/deathhistory <player_uuid>

/DELWARP
========

Deletes the named server warp.
/delwarp <name>

/DIFFICULTY
===========

Shows the current world difficulty, or changes it to peaceful, easy, normal or hard when a value is supplied.
/difficulty
/difficulty easy
/difficulty hard
/difficulty normal
/difficulty peaceful

/EFFECT
=======

Removes active status effects from the selected entities; supplying an effect removes only that effect.
/effect clear
/effect clear <targets>
/effect clear <targets> <effect>

Applies the specified status effect to the selected entities. Duration, amplifier and particle visibility can be supplied; infinite makes it last indefinitely.
/effect give <targets> <effect>
/effect give <targets> <effect> <seconds>
/effect give <targets> <effect> <seconds> <amplifier>
/effect give <targets> <effect> <seconds> <amplifier> <hideParticles>
/effect give <targets> <effect> infinite
/effect give <targets> <effect> infinite <amplifier>
/effect give <targets> <effect> infinite <amplifier> <hideParticles>

/ENCHANT
========

Adds the specified enchantment to the item held by each selected player, subject to normal compatibility and level rules.
/enchant <targets> <enchantment>
/enchant <targets> <enchantment> <level>

/EXPERIENCE
===========

Adds experience to the selected players. Negative amounts subtract experience. Choose points or levels; omitted units use points.
/experience add <targets> <amount>
/experience add <targets> <amount> levels
/experience add <targets> <amount> points

Shows the selected player's current experience points or levels.
/experience query <targets> levels
/experience query <targets> points

Sets the selected players' experience to the supplied number of points or levels.
/experience set <targets> <amount>
/experience set <targets> <amount> levels
/experience set <targets> <amount> points

/FORCELOAD
==========

Marks the selected chunk(s) to remain loaded even without players nearby.
/forceload add <from>
/forceload add <from> <to>

Lists force-loaded chunks, or checks whether the specified chunk is force-loaded.
/forceload query
/forceload query <pos>

Removes force-load assignments for the selected chunks. remove all removes all such assignments in the current dimension.
/forceload remove <from>
/forceload remove <from> <to>
/forceload remove all

/FTBCHUNKS
==========

Toggles your ability to bypass FTB Chunks claim protection for staff work.
/ftbchunks admin bypass_protection

Claims the specified chunks on behalf of the selected team/player.
/ftbchunks admin claim_as <team>
/ftbchunks admin claim_as <team> <radius_in_blocks>
/ftbchunks admin claim_as <team> <radius_in_blocks> <anchor>
/ftbchunks admin claim_as <team> <radius_in_blocks> <anchor> <dimension>

Adds to the selected player's extra claim-chunk allowance.
/ftbchunks admin extra_claim_chunks <player> add <number>

Shows the selected player's extra claim-chunk allowance.
/ftbchunks admin extra_claim_chunks <player> get

Sets the selected player's extra claim-chunk allowance to the supplied number.
/ftbchunks admin extra_claim_chunks <player> set <number>

Adds to the selected player's extra force-loaded-chunk allowance.
/ftbchunks admin extra_force_load_chunks <player> add <number>

Shows the selected player's extra force-loaded-chunk allowance.
/ftbchunks admin extra_force_load_chunks <player> get

Sets the selected player's extra force-loaded-chunk allowance.
/ftbchunks admin extra_force_load_chunks <player> set <number>

Opens the claim interface for the selected team/player so you can administer its claims.
/ftbchunks admin open_claim_gui_as <team>

Removes claims on behalf of the selected team/player.
/ftbchunks admin unclaim_as <team>
/ftbchunks admin unclaim_as <team> <radius_in_blocks>
/ftbchunks admin unclaim_as <team> <radius_in_blocks> <anchor>
/ftbchunks admin unclaim_as <team> <radius_in_blocks> <anchor> <dimension>

Removes claims in the specified dimension for the command's selected owner/scope.
/ftbchunks admin unclaim_dimension
/ftbchunks admin unclaim_dimension <dimension>

Removes all claims in the command's selected owner/scope.
/ftbchunks admin unclaim_everything

Removes force-load assignments in the command's selected owner/scope.
/ftbchunks admin unload_everything

Shows the staff visualization of loaded chunks.
/ftbchunks admin view_loaded_chunks
/ftbchunks admin view_loaded_chunks <dimension>

Clears the staff loaded-chunk visualization.
/ftbchunks admin view_loaded_chunks reset
/ftbchunks admin view_loaded_chunks reset <dimension>

/FTBQUESTS
==========

Changes whether quest rewards are blocked for the selected scope.
/ftbquests block_rewards
/ftbquests block_rewards <enabled>
/ftbquests block_rewards <enabled> <player>

Marks the selected quest/task complete for the specified team/player.
/ftbquests change_progress <players> complete <quest_object>

Marks all quests complete for the selected team/player.
/ftbquests change_progress <players> complete-all

Resets the selected quest/task progress for the specified team/player.
/ftbquests change_progress <players> reset <quest_object>

Resets all quest progress for the selected team/player.
/ftbquests change_progress <players> reset-all

Changes quest editing mode, enabling or disabling changes to the quest book.
/ftbquests editing_mode
/ftbquests editing_mode <enabled>
/ftbquests editing_mode <enabled> <player>

Changes whether quest progress is locked.
/ftbquests locked
/ftbquests locked <enabled>
/ftbquests locked <enabled> <player>

Reloads quest data.
/ftbquests reload

Reloads quest definitions from disk.
/ftbquests reload quests

Reloads saved quest team progress from disk.
/ftbquests reload team_progress

/FTBTEAMS
=========

Forces a player to join the specified team.
/ftbteams force-add <team> <players>

Disbands a team administratively.
/ftbteams force-disband <team>

Forces a player out of a team.
/ftbteams force-remove <team> <players>

Opens or changes another party's settings.
/ftbteams party settings_for <team> <key>
/ftbteams party settings_for <team> <key> <value>

Transfers ownership of another party to the selected player.
/ftbteams party transfer_ownership_for <team> <player_id>

/KICK
=====

/kick <targets>

=====

/LOOTR
======

Clears stored Lootr inventories for the named player, resetting their saved loot contents.
/lootr clear
/lootr clear <profile>

Shows the unique ID of the Lootr container you are standing on.
/lootr id

Opens the stored inventory of the container you stand on as the named player.
/lootr open_as
/lootr open_as <profile>

Opens the stored inventory of the container you stand on as the player identified by UUID.
/lootr open_as_uuid
/lootr open_as_uuid <uuid>

Lists the players/UUIDs that have opened the Lootr container at the supplied location.
/lootr openers <location>

Schedules the Lootr container you stand on to refresh using the configured delay.
/lootr refresh

/MUTE
=====

Prevents the selected player from sending chat messages. Without a duration, the mute lasts until it is removed with /unmute.
/mute <player>

Prevents the selected player from sending chat messages. The duration uses s, m, h, d or w, for example 30m or 2h.
/mute <player> <until>

/NERUINA
========

Cancels your pending GitHub sign-in used by Neruina's issue-reporting system. This does not disconnect a Minecraft player.
/neruina cancel_login

Clears Neruina's tracked ticking-error records.
/neruina clear_tracked

Shows the ticking-error record ID for the selected entity or block entity; targeting a player checks the item they are holding.
/neruina id <entity>
/neruina id <pos>

Shows details of the selected Neruina ticking exception.
/neruina info <id>

Removes the selected entity/entities if Neruina has marked them as errored.
/neruina kill <entity>

Reloads Neruina configuration.
/neruina reload

Produces a report for the selected ticking exception.
/neruina report <id>

Resumes the suspended entity, block entity, block state or item stack named by the command. Its error may recur if the cause is still present.
/neruina resume block_entity <pos>
/neruina resume block_state <pos>
/neruina resume entity <entity>
/neruina resume item_stack <player>

Shows the objects Neruina has suspended because of ticking errors.
/neruina show_suspended

/TB
===

Opens the selected player's equipped Traveler's Backpack, or the backpack block at the supplied coordinates.
/tb access <pos>
/tb access <target>

Replaces the equipped Traveler's Backpack with a cleared copy, retaining its tier; the original is returned to the player's inventory or dropped if full.
/tb clear
/tb clear <player>

/tb remove

/tb restore <target> <backpack_id>

Empties the selected equipped or placed Traveler's Backpack, dropping its stored items, tools and upgrades into the world at its location.
/tb unpack <pos>
/tb unpack <target>

/WORLDBORDER
============

Adds the supplied amount to the border diameter, optionally over a timed transition.
/worldborder add <distance>
/worldborder add <distance> <time>

Sets the world border's center coordinates.
/worldborder center <pos>

/worldborder damage amount <damagePerBlock>
